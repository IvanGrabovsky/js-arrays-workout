Модуль 5: Масиви в JavaScript — Повний конспект

Масив (Array) — це впорядкована колекція даних, де кожен елемент має свій числовий порядковий номер (індекс), який починається з 0. Масиви в JavaScript є динамічними за розміром і можуть зберігати елементи будь-яких типів.

🧠 Організація в памʼяті та адресація

У низькорівневих мовах масив — це неперервний блок памʼяті. Адреса будь-якого елемента обчислюється миттєво за формулою:
Address = BaseAddress + Index * ElementSize. Саме тому індексація починається з 0: перший елемент знаходиться зі зміщенням 0 * ElementSize від початку блоку! Доступ до будь-якого елемента за індексом відбувається за O(1) (константний час).

🔗 Посилання (Reference) vs Значення

Змінна, в яку записано масив, зберігає не самі дані, а посилання на область у купі (Heap). Якщо скопіювати змінну let b = a, обидві змінні вказуватимуть на один і той самий масив. Для незалежної копії використовують спред-синтаксис: let copy = [...a] або a.slice().

🛠️ Створення масивів

• Літерал: const arr = [1, 2, 3]; (найбільш рекомендований)
• Конструктор: new Array(5); (створює 5 порожніх комірок)
• Заповнення: new Array(3).fill(0); -> [0, 0, 0]
• Діапазон: Array.from({ length: 5 }, (_, i) => i + 1);

⚡ Стек (LIFO) та Черга (FIFO)

• push() / pop(): додавання та вилучення з кінця масиву. Працюють за O(1).
• unshift() / shift(): додавання та вилучення з початку масиву. Працюють за O(n), тому що всі наступні елементи повинні зсунутися у памʼяті!

✂️ slice проти splice

• slice(start, end): НЕ мутує оригінал. Повертає новий підмасив.
• splice(start, count, ...items): МУТУЄ оригінальний масив на місці. Дозволяє видаляти, вставляти або замінювати елементи.

📊 Багатовимірні масиви (2D)

Масив, елементами якого є інші масиви: matrix[row][col]. Застосовується для ігрових полів (шахи, хрестики-нулики, морський бій), електронних таблиць, зображень та координатних сіток.
