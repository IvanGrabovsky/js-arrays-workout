Масиви в JavaScript — Повний теоретичний посібник

Масив (Array) — це одна з фундаментальних і найчастіше використовуваних структур даних у мові JavaScript. У цьому конспекті вичерпно розібрано внутрішній устрій масивів у пам'яті, причину нумерації з 0, роботу з посиланнями, усі базові та сучасні методи, багатовимірні матриці та типові практичні задачі.

1. Що таке масив?

Масив (Array) — це впорядкована колекція даних, де кожен елемент має свій числовий порядковий номер, який називається індексом. Індексація в JavaScript завжди починається з 0.

📈 Динамічними за розміром

Вам не потрібно заздалегідь декларувати розмір масиву. Ви можете вільно додавати та видаляти елементи під час виконання програми, і пам'ять підлаштується автоматично.

🧩 Гетерогенними за типами

Один і той самий масив може одночасно зберігати числа, рядки, булеві значення, об'єкти, інші масиви і навіть функції: [42, "привіт", true, { id: 1 }].

📦 Об'єктами за природою

Технічно в JS масив — це спеціалізований підтип об'єкта (typeof [] === 'object'), чиї ключі є числами (рядковими індексами), з автоматично керованою властивістю length.

2. Цілі та завдання масивів

Масиви створюються для розв'язання таких ключових завдань програмування:

  • Зберігання однорідних наборів сутностей: список товарів у кошику інтернет-магазину, черга сповіщень користувача, перелік оцінок учнів, координати пікселів на екрані.
  • Масова пакетна обробка даних: швидкий перебір усіх елементів за допомогою циклів, фільтрація за складними критеріями, сортування та трансформування даних.
  • Реалізація класичних структур даних: моделювання Стека (LIFO), Черги (FIFO), Дека та Двовимірних матриць.

3. Відмінність масивів від звичайних змінних

Звичайна змінна зберігає лише одне скалярне значення (число, рядок тощо). Якщо вам потрібно зберегти 100 показників температури, використання звичайних змінних temp1, temp2, ..., temp100 паралізує програму — їх неможливо автоматично перебрати в циклі чи передати як єдиний аргумент у функцію.

Масив дає змогу пов'язати тисячі значень із єдиною змінною: const temperatures = [18.5, 19.2, 21.0, 17.8];.

Важливо: Примітиви копіюються за значенням, а масиви — за посиланням!
Коли ви присвоюєте масив іншій змінній (const b = a;), копіюються не самі дані, а лише посилання (адреса в пам'яті). Зміна елемента через змінну b негайно відобразиться у змінній a.
JavaScript 

// Копіювання за посиланням (Reference):
const original = [1, 2, 3];
const alias = original; // alias вказує на той самий блок пам'яті!

alias.push(4);
console.log(original); // [1, 2, 3, 4] — оригінал теж змінився!

// Справжнє незалежне поверхневе копіювання:
const independentCopy = [...original]; // або original.slice()
independentCopy.push(99);
console.log(original); // [1, 2, 3, 4] — оригінал незмінний!

4. Як влаштовані масиви в памʼяті. Індекси. Нумерація з 0

У комп'ютерній пам'яті масив спочатку задумувався як неперервний послідовний блок комірок пам'яті. Змінна в стеку зберігає початкову адресу (BaseAddress) першого елемента в купі (Heap).

Стек (Stack): variable "languages" ──> вказує на адресу 0x1000 у Купі (Heap) Купа (Heap) — неперервний блок пам'яті: ┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐ │ Адреса: 0x1000 │ Адреса: 0x1008 │ Адреса: 0x1010 │ Адреса: 0x1018 │ │ Індекс: 0 │ Індекс: 1 │ Індекс: 2 │ Індекс: 3 │ │ Дані: "JS" │ Дані: "HTML" │ Дані: "CSS" │ Дані: "React" │ │ Зсув: +0 байт │ Зсув: +8 байт │ Зсув: +16 байт│ Зсув: +24 байт│ └─────────────────┴─────────────────┴─────────────────┴─────────────────┘

Чому індексація починається саме з 0?
Індекс — це не просто порядковий номер, це фізичне зміщення (offset) від базової адреси початку масиву. Адреса будь-якого елемента обчислюється процесором за формулою:
Адреса_елемента(i) = Базова_адреса + (i * Розмір_елемента)

Для першого елемента зміщення дорівнює нулю: 0 * Розмір_елемента = 0. Перший елемент розташований прямо за базовою адресою! Якби індексація починалася з 1, комп'ютеру доводилося б щоразу виконувати зайву арифметичну операцію віднімання (i - 1) для кожного звернення до пам'яті. Завдяки цій формулі доступ до будь-якого елемента за індексом відбувається миттєво — за O(1) (константний час).

5. Створення масивів ([] та конструктор Array())

У JavaScript існує кілька способів ініціалізації нового масиву:

JavaScript 

// 1. Літерал масиву [] (Найбільш рекомендований, швидкий та зручний спосіб):
const fruits = ['яблуко', 'банан', 'ківі'];
const empty = [];

// 2. Конструктор new Array():
const colors = new Array('червоний', 'синій'); // ['червоний', 'синій']

// ⚠️ ПАСТКА конструктора Array(n) з одним числовим аргументом:
const badArr = new Array(3); // Створює [empty × 3] — масив з 3 "дірками" без значень!
console.log(badArr.length);  // 3
console.log(badArr[0]);       // undefined (порожня комірка)

// Правильне заповнення через .fill():
const zeros = new Array(3).fill(0); // [0, 0, 0]

// 3. Array.of() — позбавлений підступної поведінки new Array:
const singleNum = Array.of(3); // [3] (масив з одним елементом 3)

// 4. Array.from() — генерація послідовностей:
const range = Array.from({ length: 5 }, (_, i) => i + 1); // [1, 2, 3, 4, 5]

// 5. Перевірка на масив:
console.log(Array.isArray(fruits)); // true
console.log(typeof fruits);         // "object" (ніколи не використовуйте typeof для перевірки масивів!)

6. Доступ до елементів масиву

Звернення до комірок здійснюється за числовим індексом у квадратних дужках.

JavaScript 

const stack = ['HTML', 'CSS', 'JavaScript'];

// 1. Звернення за індексом:
console.log(stack[0]); // 'HTML' (перший елемент)
console.log(stack[1]); // 'CSS'
console.log(stack[99]); // undefined (неіснуючий індекс не ламає програму, а повертає undefined)

// 2. Отримання останнього елемента:
console.log(stack[stack.length - 1]); // 'JavaScript' (класичний спосіб)
console.log(stack.at(-1));             // 'JavaScript' (сучасний метод at: -1 останній, -2 передостанній)

// 3. Зміна значення:
stack[1] = 'Tailwind CSS';
console.log(stack); // ['HTML', 'Tailwind CSS', 'JavaScript']

// 4. Властивість length:
console.log(stack.length); // 3

// ⚠️ length можна змінювати вручну!
stack.length = 2; // Примусове обрізання: видаляє третій елемент назавжди!
console.log(stack); // ['HTML', 'Tailwind CSS']

stack.length = 0; // Найшвидший ідіоматичний спосіб повністю очистити масив
console.log(stack); // []

7. Перебір масиву (for, while, for...of)

Для послідовної обробки кожного елемента колекції використовуються цикли:

JavaScript 

const numbers = [10, 20, 30, 40];

// Спосіб А: Класичний for (повний контроль над індексом i):
for (let i = 0; i < numbers.length; i++) {
  console.log(`Індекс ${i} має значення ${numbers[i]}`);
}

// Зворотний перебір:
for (let i = numbers.length - 1; i >= 0; i--) {
  console.log(numbers[i]);
}

// Спосіб Б: Сучасний for...of (найчистіший синтаксис для роботи зі значеннями):
for (const num of numbers) {
  console.log(num); // прямо отримуємо значення без numbers[i]
}

// Спосіб В: Цикл while:
let idx = 0;
while (idx < numbers.length) {
  console.log(numbers[idx]);
  idx++;
}

// ⚠️ ЧОМУ НЕ МОЖНА ВИКОРИСТОВУВАТИ for...in ДЛЯ МАСИВІВ?
// for...in призначений для перебору ключів звичайних об'єктів. Він перебирає властивості
// у довільному порядку, перетворює числові індекси на рядки ("0", "1") та захоплює зайві поля з прототипу.

8. Операції з масивами (push, pop, shift, unshift, includes, indexOf)

Масиви дозволяють працювати з обома своїми кінцями. Зверніть особливу увагу на часову складність:

⚡ Робота з кінцем: push / pop (O(1))

• arr.push(x) — додає елемент у кінець масиву. Працює миттєво за O(1).
• arr.pop() — знімає останній елемент і повертає його. Також O(1).
Разом вони утворюють класичний Стек (LIFO — Last In, First Out).

🐢 Робота з початком: unshift / shift (O(n))

• arr.unshift(x) — додає на початок (індекс 0).
• arr.shift() — вилучає перший елемент.
Обидві операції змушують рушій пересунути всі інші N елементів на одну позицію в пам'яті, тому вони працюють набагато повільніше — за O(n).

JavaScript 

const list = ['A', 'B'];

list.push('C');      // ['A', 'B', 'C'] —> O(1)
const last = list.pop(); // last = 'C', list = ['A', 'B'] —> O(1)

list.unshift('Start'); // ['Start', 'A', 'B'] —> O(n)
const first = list.shift(); // first = 'Start', list = ['A', 'B'] —> O(n)

// Пошук та перевірка наявності:
const animals = ['кіт', 'собака', 'папуга'];

// .includes(val) —> повертає true/false:
console.log(animals.includes('собака')); // true
console.log(animals.includes('вовк'));   // false

// .indexOf(val) —> повертає перший індекс або -1:
console.log(animals.indexOf('папуга')); // 2
console.log(animals.indexOf('тигр'));   // -1

9. Робота з підмасивами (slice, splice, concat)

Це одна з найважливіших тем, де початківці часто припускаються помилок через різницю в мутабельності:

✂️ slice(start, end) — ІМУТАБЕЛЬНИЙ

НЕ змінює оригінальний масив. Копіює елементи від індексу start до end (сам індекс end не включається!). Повертає абсолютно новий масив.

🔪 splice(start, deleteCount, ...items) — МУТУЮЧИЙ

ЗМІНЮЄ (мутує) оригінальний масив на місці! Починаючи з індексу start, вирізає deleteCount елементів і вставляє нові items. Повертає масив видалених елементів.

JavaScript 

// Приклад slice (безпечний):
const letters = ['a', 'b', 'c', 'd', 'e'];
const part = letters.slice(1, 4); // від індексу 1 до 3 включно
console.log(part);    // ['b', 'c', 'd']
console.log(letters); // ['a', 'b', 'c', 'd', 'e'] (оригінал не постраждав)

// Приклад splice (мутація оригіналу):
const items = ['ніж', 'вилка', 'ложка', 'тарілка'];
// Видалити 1 елемент починаючи з індексу 2 ('ложка') та вставити замість нього 'чашка':
const removed = items.splice(2, 1, 'чашка');
console.log(removed); // ['ложка']
console.log(items);   // ['ніж', 'вилка', 'чашка', 'тарілка']

// Об'єднання масивів concat vs Spread:
const a = [1, 2];
const b = [3, 4];
const combined = a.concat(b, [5, 6]); // [1, 2, 3, 4, 5, 6] (новий масив)
const modern = [...a, ...b, 7, 8];    // [1, 2, 3, 4, 7, 8]

10. Багатовимірні масиви (Матриці 2D, 3D)

Багатовимірний масив — це масив, елементами якого є інші масиви. Найпоширенішим є двовимірний масив (матриця, сітка, таблиця), де перший індекс визначає рядок (row), а другий — стовпець (col).

Матриця 3x3: стовпець 0 стовпець 1 стовпець 2 рядок 0 ──> [ 11, 12, 13 ] рядок 1 ──> [ 21, 22, 23 ] рядок 2 ──> [ 31, 32, 33 ] Звернення: matrix[1][2] обере рядок 1 ("21, 22, 23"), а потім стовпець 2 —> значення 23
JavaScript 

// Створення двовимірного масиву:
const grid = [
  ['X', 'O', 'X'],
  ['O', 'X', 'O'],
  ['O', 'X', 'X']
];

console.log(grid[0][0]); // 'X' (верхній лівий кут)
console.log(grid[1][1]); // 'X' (центр поля)

// ⚠️ ПАСТКА при створенні порожньої матриці:
// НЕ РОБІТЬ ТАК:
const badGrid = new Array(3).fill(new Array(3).fill(0));
badGrid[0][0] = 99;
// ЖАХ! Усі три рядки посилаються на один і той самий масив: badGrid[1][0] теж стало 99!

// ПРАВИЛЬНЕ СТВОРЕННЯ МАТРИЦІ (незалежні рядки):
const goodGrid = Array.from({ length: 3 }, () => new Array(3).fill(0));
goodGrid[0][0] = 99;
console.log(goodGrid[1][0]); // 0 (кожен рядок незалежний!)

// Перебір матриці двома вкладеними циклами:
for (let r = 0; r < grid.length; r++) {
  for (let c = 0; c < grid[r].length; c++) {
    console.log(`Рядок ${r}, Стовпець ${c}: ${grid[r][c]}`);
  }
}

11. Практичні приклади створення та використання одновимірних і багатовимірних масивів

Розгляньмо кілька популярних прикладів з реальних веб-додатків:

JavaScript 

// Приклад 1: Підрахунок вартості кошика інтернет-магазину
const cart = [
  { title: 'Ноутбук', price: 25000, qty: 1 },
  { title: 'Мишка', price: 800, qty: 2 },
  { title: 'Килимок', price: 300, qty: 1 }
];

let totalAmount = 0;
for (const item of cart) {
  totalAmount += item.price * item.qty;
}
console.log(`Загальна сума до сплати: ${totalAmount} грн`); // 26900 грн

// Приклад 2: Пошук екстремумів (найбільшого та найменшого числа)
const scores = [85, 92, 45, 98, 77, 88];
let min = scores[0];
let max = scores[0];

for (let i = 1; i < scores.length; i++) {
  if (scores[i] < min) min = scores[i];
  if (scores[i] > max) max = scores[i];
}
console.log(`Мінімум: ${min}, Максимум: ${max}`); // 45 та 98

// Приклад 3: Перевірка діагоналі в грі "Хрестики-нулики"
function checkMainDiagonal(board) {
  const first = board[0][0];
  if (!first) return false;
  for (let i = 1; i < board.length; i++) {
    if (board[i][i] !== first) return false;
  }
  return true;
}
