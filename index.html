    1. Зробіть Fork репозиторію на GitHub
    
      
    На сторінці репозиторію натисніть кнопку Fork угорі праворуч, щоб створити власну копію у своєму GitHub-акаунті.
    

      
    2. Склонуйте ваш форк та встановіть залежності
    
      
    git clone https://github.com/ВАШ_НІК/js-arrays-workout.git
cd js-arrays-workout
npm install
    

      
    3. Запустіть автотести
    
      
    # Запуск усіх тестів через термінал:
npm test

# Або запуск у режимі реального часу (watch mode):
npm run test:watch

# Або відкрийте цей інтерактивний веб-тренажер:
npm run dev
    

      
    4. Пишіть код у файлах папки src/
    
      
    Кожен модуль має свій файл (наприклад, src/01-forEach.js, src/02-map.js). Пишіть свій код замість // TODO.
    

      
    5. Створіть гілку, зафіксуйте зміни та відкрийте Pull Request
    
      
    git checkout -b solution/ivan-ivanov
git add src/
git commit -m "feat: complete array methods tasks"
git push origin solution/ivan-ivanov
    
      
    Перейдіть на GitHub і створіть Pull Request з вашої гілки в основний репозиторій викладача. Автотести GitHub Actions автоматично протестують ваш код і покажуть зелену галочку!
