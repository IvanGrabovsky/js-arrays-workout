## 📚 Програма тренажера (14 модулів, 94 завдання)

### Частина 1: Фундаментальні основи масивів
1. **Модуль 1: Створення масивів, індексація з 0 та пам'ять (10 завдань)**
   - Що таке масив, відмінність від простих змінних, організація в памʼяті, `[]`, `new Array()`, `Array.from()`.
2. **Модуль 2: Доступ до елементів, зміна значень та .length (10 завдань)**
   - Звернення за індексом, читання з кінця `arr.at(-1)`, мутація значень, скорочення та очищення через `length = 0`.
3. **Модуль 3: Перебір масивів: for, while, for...of (10 завдань)**
   - Класичний `for (let i = 0)`, зворотний перебір `while`, сучасний `for...of`, суми, екстремуми.
4. **Модуль 4: Операції стек та черга: push, pop, shift, unshift, includes, indexOf (12 завдань)**
   - LIFO стек, FIFO черга, видалення всіх входжень, циклічні зсуви вліво/вправо.
5. **Модуль 5: Робота з підмасивами: slice, splice, concat (12 завдань)**
   - Немутуючий зріз `slice`, мутуюче видалення/вставка/заміна `splice`, обʼєднання через `concat`.
6. **Модуль 6: Багатовимірні 2D масиви, сітки та матриці (12 завдань)**
   - Створення матриць `rows x cols`, доступ `matrix[r][c]`, перебір, суми рядків/колонок, транспонування, хрестики-нулики.

### Частина 2: Вищі функціональні методи та пайплайни
7. **Модуль 7: forEach — Перебір та побічні ефекти (3 завдання)**
8. **Модуль 8: map — Трансформація та проекції даних (4 завдання)**
9. **Модуль 9: filter — Фільтрація та селекція (4 завдання)**
10. **Модуль 10: find та findIndex — Точковий пошук сутності (3 завдання)**
11. **Модуль 11: some та every — Предикатна валідація (4 завдання)**
12. **Модуль 12: reduce — Агрегація та згортання даних (4 завдання)**
13. **Модуль 13: flat та flatMap — Згладжування структур (3 завдання)**
14. **Модуль 14: Boss Challenges — Бойові пайплайни методів (3 завдання)**
