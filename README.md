3. **Модуль 3**: Перебір масивів: for, while, for...of
4. **Модуль 4**: Операції стек та черга: push, pop, shift, unshift, includes, indexOf
5. **Модуль 5**: Робота з підмасивами: slice, splice, concat
6. **Модуль 6**: Розширені методи трансформації: map, filter, flat, flatMap
7. **Модуль 7**: Пошук та валідація: find, findIndex, some, every
8. **Модуль 8**: Агрегація даних: reduce, reduceRight
9. **Модуль 9**: Сортування та реверс: sort, reverse, toSorted, toReversed
10. **Модуль 10**: Багатовимірні масиви (2D матриці)
11. **Модуль 11**: Деструктуризація, Rest / Spread оператори

14. **Модуль 14**: Комерційні пайплайни та бізнес-логіка
