## 📚 Програма воркаута (14 модулів, 94 завдання)

### Частина 1: Фундаментальні основи масивів
1. **Модуль 1: Створення масивів, індексація з 0 та пам'ять (10 завдань)**  
   `src/01-create-memory.js` — Організація масивів в оперативній пам'яті, синтаксис `[]`, `new Array()`, `Array.from()`.
2. **Модуль 2: Доступ до елементів, зміна значень та .length (10 завдань)**  
   `src/02-access-length.js` — Індексація, отримання з кінця `arr.at(-1)`, мутація значень, скорочення та очищення через `length = 0`.
3. **Модуль 3: Перебір масивів: for, while, for...of (10 завдань)**  
   `src/03-traversal.js` — Класичний `for (let i = 0)`, зворотний перебір `while`, сучасний `for...of`, знаходження максимумів і мінімумів.
4. **Модуль 4: Операції стек та черга: push, pop, shift, unshift, includes, indexOf (12 завдань)**  
   `src/04-stack-queue.js` — LIFO стек, FIFO черга, детекція входження `includes`, пошук першого/останнього індексу.
5. **Модуль 5: Робота з підмасивами: slice, splice, concat (12 завдань)**  
   `src/05-subarrays.js` — Немутуюче копіювання зрізів `slice`, мутуюча заміна/видалення `splice`, об'єднання кількох масивів через `concat`.
6. **Модуль 6: Багатовимірні 2D масиви, сітки та матриці (12 завдань)**  
   `src/06-multidimensional.js` — Створення таблиць `rows x cols`, доступ `matrix[r][c]`, суми рядків та колонок, транспонування матриць.

### Частина 2: Вищі методи та функціональні поліфіли
7. **Модуль 7: forEach — Перебір та побічні ефекти (3 завдання)**  
   `src/07-forEach.js` — Створення власного поліфілу `myForEach`, обробка подій та розсилок.
8. **Модуль 8: map — Трансформація та проекції даних (4 завдання)**  
   `src/08-map.js` — Поліфіл `myMap`, DTO мапінг товарів для інтернет-магазинів, GDPR анонімізація даних.
9. **Модуль 9: filter — Фільтрація та селекція (4 завдання)**  
   `src/09-filter.js` — Поліфіл `myFilter`, валідація промокодів, відсіювання спам-коментарів.
10. **Модуль 10: find та findIndex — Точковий пошук сутності (3 завдання)**  
    `src/10-find-findIndex.js` — Поліфіли `myFind` / `myFindIndex`, аналіз логів безпеки, пошук квитків.
11. **Модуль 11: some та every — Предикатна валідація (4 завдання)**  
    `src/11-some-every.js` — Поліфіли `mySome` / `myEvery`, валідація банківських чеків та прав користувачів.
12. **Модуль 12: reduce — Агрегація та згортання даних (4 завдання)**  
    `src/12-reduce.js` — Поліфіл `myReduce`, групування об'єктів за категорією, формування рядків URL query.
13. **Модуль 13: flat та flatMap — Згладжування структур (3 завдання)**  
    `src/13-flat-flatMap.js` — Поліфіли `myFlat` / `myFlatMap`, витяг унікальних тегів із вкладених постів.
14. **Модуль 14: Boss Challenges — Бойові пайплайни методів (3 завдання)**  
    `src/14-boss-pipelines.js` — Комплексні комбіновані ланцюжки методів: аналітика продажів, смарт-плейлисти.

## 🚀 Покроковий гайд для студента (Локальна розробка)

### 1. Зробіть Fork репозиторію
1. Відкрийте головний репозиторій: [https://github.com/IvanGrabovsky/js-arrays-workout](https://github.com/IvanGrabovsky/js-arrays-workout).
2. Натисніть кнопку **Fork** (вгорі праворуч) ➔ **Create fork**.
3. У вашому профілі з'явиться персональний форк: `https://github.com/<ВАШ_НІКНЕЙМ>/js-arrays-workout`.

### 2. Клонуйте свій форк
```bash
git clone https://github.com/<ВАШ_НІКНЕЙМ>/js-arrays-workout.git
cd js-arrays-workout
```

### 3. Встановіть залежності
```bash
npm install
```

### 4. Запустіть веб-тренажер
```bash
npm run dev
```
Відкрийте `http://localhost:5173` у браузері.

### 5. Авторизуйтеся як студент
- У шапці сторінки відкрийте меню профілю учня.
- Вкажіть ваше **Прізвище та Ім'я**, **Навчальну групу** та **GitHub Username**.
- Натисніть **«Зберегти»**, щоб прогрес виконання фіксувався в системі викладача.

### 6. Напишіть рішення у папці `src/`
Кожне завдання — це експортована функція.  
Приклад (`src/01-create-memory.js`):
```javascript
// Завдання 1.1: Створення масиву через квадратні дужки []
export function createArrayLiteral(a, b, c) {
  return [a, b, c];
}
```

### 7. Запустіть автотести (Vitest)
```bash
# Запустити всі 223 автотести
npm test

# Режим автоматичного перезапуску при зміні файлів
npm run test:watch

# Запустити тести тільки одного модуля
npx vitest run test/01-create-memory.test.js
```

### 8. Зафіксуйте рішення в Git та відправте на GitHub
```bash
git status
git add .
git commit -m "feat(arrays): complete modules 1 to 6"
git push origin main
```

### 9. Створіть Pull Request (Здача ДЗ)
1. Відкрийте ваш форк на GitHub.
2. Натисніть **Contribute** ➔ **Open pull request**.
3. Заголовок PR: `[ДЗ Масиви] Прізвище Ім'я — Група`.
4. Натисніть **Create pull request**. Робот GitHub Actions автоматично протестує ваш код та поставить зелену позначку успішності.
